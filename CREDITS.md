# Crédits

Le code, les images et les sons de Ballmania sont faits pour le jeu : les couvertures,
l'image de partage et les vidéos des portails sont dessinées par notre code
(`marketing/crazygames`), l'icône (`public/favicon.svg`) est un dessin vectoriel du jeu, et
la musique comme les bruitages sont synthétisés en direct (`src/audio`), sans aucun
échantillon. Seules les polices viennent d'ailleurs.
